---
description: Committa alla ändringar och pusha till GitHub
---

Committa och pusha projektets ändringar till GitHub:

1. Kör `git status` och `git diff` för att se vad som ändrats. Finns inga ändringar, säg det och avsluta.
2. Stega alla relevanta filer. Ta inte med hemligheter (t.ex. `.env`, API-nycklar) eller tillfälliga filer.
3. Skriv ett kort, beskrivande commit-meddelande på svenska som sammanfattar ändringarna.
4. Pusha till `origin` på nuvarande branch.
5. Rapportera kort vad som committades och att pushen lyckades (eller vad som gick fel).
